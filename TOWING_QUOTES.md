## Live routing extension
- Optional address-to-address or opted-in browser GPS-to-address road route via Google Routes API computeRoutes, server key DV_GOOGLE_MAPS_SERVER_KEY; DV_ROUTE_ENABLED=true only after privacy notice, terms, quota/WAF rate limits and key restrictions are configured. No API key created or spend enabled. Default off. Addresses are sent to Google with Alberta, Canada appended; GPS is bounded to Alberta's approximate bounding box. Both endpoints are geocoded transiently with Google Geocoding API, verified against Canadian/Alberta components and selected communities; Diamond Valley aliases are allowed because the municipality amalgamated. Ambiguous rural addresses fail closed; results never enter the archive. Address autocomplete, finer neighborhood verification and independent archive-compatible geocoding are pending. Enable Geocoding API as well as Routes API on the restricted key. Route estimates for normal cars are not truck-specific navigation.
- Driving distance shown separately. Flat-rate local/Okotoks/High River pricing takes priority. Non-flat routes only price when owner-approved DV_LONG_DISTANCE_BASE_CENTS is set (e.g. 12500 would mean $125 + $4/km; example, not approved). Recovery route distance becomes chargeable only with DV_RECOVERY_ROUTE_BILLING=true, after mileage basis is approved. No assumed round-trip or yard deadhead. No storage or publication of Google route results or route-derived quotes; provider policy restricts persistent storage and indexing. Manual community quotes still use the existing moderated archive. For SEO archive of routed estimates, select an independently licensed routing source (e.g. self-hosted OSRM/OSM after licensing review) or obtain suitable provider permissions. Keep raw addresses and pins out of public content. See https://developers.google.com/maps/documentation/routes/policies and https://developers.google.com/maps/documentation/routes/compute_route_directions. Official logo where space permits and privacy/terms disclosures required before launch. No deployment performed.
